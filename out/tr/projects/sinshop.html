SinShopGeliştirme ProjesiÇok Dilli E-Ticaret Platformu

Güvenilir İşlemler İçin Tasarlanmış E-Ticaret Altyapısı.

Dört dilde bir online mağaza: ürün arama, sepet, sipariş ve ödeme. Aynı anda çok sayıda müşteri satın alırken bile stok ve sipariş tutarlarının doğru kalması için tasarlandı.

Kaynak kodu GitHub'da gör

Kapsam notu:Ödeme çağrıları, depoda bulunmayan geçerli bir ZarinPal üye işyeri yapılandırması gerektirir. Mağaza arayüzü yerel demo kataloğuyla incelenebilir.

Problem

E-ticarette asıl zorluk ürünleri göstermek değil; aynı anda çok sayıda kişi alışveriş yaparken sepet, stok ve siparişleri tutarlı tutmak ve ödemeyi güvenli şekilde ödeme altyapısına aktarmaktır.

Proje Kapsamı

Full-stack bir e-ticaret projesi: hesaplar, katalog, sepet, sipariş ve ödemeler için Django REST Framework backend'i ve dil önekli rotalar ile Farsça RTL desteğine sahip Next.js App Router mağaza arayüzü.

Temel Özellikler

  • JWT giriş ve yenileme ile telefon numarası tabanlı kullanıcı modeli
  • Arama, sıralama, filtre, indirim ve stok bilgisi içeren katalog
  • Sahiplik kontrollü misafir ve üye sepetleri
  • Sepeti, kalemleri ve ürünleri tek bir işlemde kilitleyen ödeme adımı
  • Satın alma anındaki birim fiyatı saklayan sipariş kalemleri
  • ZarinPal ödeme isteği ve geri dönüş doğrulaması
  • Farsça RTL dahil dört dilde Next.js mağaza
  • OpenAPI şeması, Swagger UI, hız sınırlama, health ve readiness uç noktaları

Teknoloji Yığını

  • Django
  • DRF
  • Next.js
  • React
  • Celery
  • Redis
  • JWT
Teknik ayrıntılarMimari, kritik akış ve mühendislik kararları

Mimari

Tarayıcı → Next.js mağaza → aynı kaynaklı API yönlendirmesi → Django REST Framework → veritabanı. Arka plan görevlerini Redis aracılı Celery işçileri yürütür; ödeme başlatma ve doğrulama ZarinPal ödeme sınırından geçer.

  1. Browser

    en · fa · tr · ru

  2. Next.js storefront

    App Router · RTL

  3. Same-origin rewrite

    /backend-api/*

  4. Django REST Framework

    account · shop · cart · orders · payment

  5. Database

    SQLite local · DATABASE_URL

Celery + Redis

abandoned carts · payment notifications

ZarinPal

payment request · callback verify

Kritik Akış

  1. POST checkout
  2. BEGIN transaction
  3. SELECT … FOR UPDATE (cart, items, products)
  4. validate active + stock
  5. create Order + unit-price snapshots
  6. decrement stock · clear cart
  7. COMMIT
  8. payment request → gateway callback → verify

Teknik Zorluklar

  • İki müşteri aynı ürünü satın alırken fazla satışı önlemek
  • Fiyatlar değiştikten sonra sipariş toplamlarını doğru tutmak
  • Misafir ve üye sepetlerini sahiplik sızıntısı olmadan desteklemek

Mühendislik Kararları

  • Stok yalnızca bir kez düşsün diye ödeme sırasında satır düzeyinde kilitleme
  • Tüm parasal değerler için DecimalField — kayan noktalı para yok
  • Fiyat anlık görüntüsü tutan değiştirilemez sipariş kalemleri
  • Açık CORS izin listesi ve ayrı anonim / kullanıcı hız limitleri

Jokar DentalВ процессеПремиальный дизайн и разработка сайта

Многоязычный опыт для пациентов стоматологической клиники.

Сайт на четырёх языках для стоматологической клиники в Анталье и Стамбуле: ведёт иностранных пациентов от понятной информации о лечении к заявке на консультацию.

Исходный код на GitHub

Примечание:Проект находится в разработке и ещё не запущен публично.

Задача

Иностранные пациенты сравнивают клиники на своём языке. Клинике нужен был сайт, который понятно объясняет лечение, выглядит премиально и превращает интерес в заявки на консультацию.

Объём проекта

Дизайн и разработка публичного сайта на персидском, английском, немецком и турецком языках, отдельные страницы лечения и бэкенд для заявок на консультацию с ролями сотрудников.

Ключевые возможности

  • Четыре языка с языковой маршрутизацией и персидским RTL
  • Страницы лечения с интерактивными разделами
  • Форма записи на консультацию с сохранением в PostgreSQL
  • Роли сотрудников в Django Admin с двухфакторным входом вне разработки
  • Блокировка входа после повторных неудачных попыток
  • Сборка падает, если в каком-либо языке не хватает ключа перевода
  • Сквозные тесты Playwright, включая RTL и режим уменьшенного движения

Технологии

  • Next.js
  • Django
  • DRF
  • PostgreSQL
  • Tailwind CSS
  • Playwright
Технические подробностиАрхитектура, критический процесс и инженерные решения

Архитектура

Фронтенд Next.js App Router (TypeScript, Tailwind CSS) → бэкенд Django REST Framework → PostgreSQL. Заявки сначала сохраняются, затем сотрудники получают уведомление; неудачные уведомления отправляются повторно.

  1. Visitor

    fa · en · de · tr

  2. Next.js App Router

    TypeScript · Tailwind CSS

  3. Django REST Framework

    consultation requests

  4. PostgreSQL

    leads · staff roles

Staff notifications

stored first · retried on failure

Критический процесс

  1. Consultation form
  2. validate input
  3. store request in PostgreSQL
  4. notify staff
  5. retry pending notifications

Технические сложности

  • Одинаковая медицинская информация на четырёх языках
  • Насыщенная анимация без потери скорости страниц
  • Осознанный дизайн RTL вместо простого зеркалирования

Инженерные решения

  • Тест, проверяющий, что одни и те же факты есть во всех языках
  • Статичная версия каждой анимации в режиме уменьшенного движения
  • Только логические свойства CSS, защищённые тестом
